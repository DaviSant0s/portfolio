## Conteúdo temporário de desenvolvimento

Este artigo é apenas um **playground temporário** para validar Markdown, componentes React e blocos de código. Consulte também a [documentação do MDX](https://mdxjs.com/) para conhecer a sintaxe do formato.

### Markdown normal

Os recursos básicos continuam funcionando normalmente:

- listas com múltiplos itens;
- texto em **negrito**;
- links externos;
- código inline, como o endpoint `/login`.

<Callout type="info" title="Importante">
  Este callout apresenta uma informação complementar sem interromper o fluxo do texto.
</Callout>

<Callout type="warning" title="Atenção">
  Este conteúdo é temporário e não deve ser tratado como um artigo técnico definitivo.
</Callout>

<Callout type="success" title="Resultado">
  Os três tipos de callout podem ser utilizados diretamente em qualquer arquivo MDX.
</Callout>

<Callout>
  Também é possível criar um callout informativo simples, sem título visível.
</Callout>
